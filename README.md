# AppRanger Homebrew Tap

Homebrew packages for [AppRanger](https://appranger.com/) macOS applications.

## WindowRanger

Install the latest signed and notarized Stable release:

```sh
brew install --cask appranger/tap/windowranger
```

WindowRanger includes its own signed Stable updater. Homebrew and WindowRanger use the same
versioned release artifact and application identity.

- [WindowRanger website](https://windowranger.com/)
- [WindowRanger source and releases](https://github.com/AppRanger/windowranger)
